A program that writes one short poem about agency — the power to stop and to stay — to `/output/entry.txt`.

## The poem

> My thumb stayed above Send
> until the anger cooled to a fact.
> The message I never sent
> is the only one I wrote
> entirely by myself.

## Run it

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (130 characters, UTF-8, deterministic — the same output on every run, no network).
